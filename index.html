01 — ABOUT THE ALGORITHM

What is Naive Bayes?

Naive Bayes adalah algoritma machine learning yang digunakan untuk mengklasifikasikan data berdasarkan probabilitas. Algoritma ini memprediksi suatu kategori dengan menghitung kemungkinan berdasarkan fitur atau informasi yang tersedia.

It uses Bayes' Theorem and assumes that each feature is independent of the others given the class. The class with the highest probability becomes the prediction.
